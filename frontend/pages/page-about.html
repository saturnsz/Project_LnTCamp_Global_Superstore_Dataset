StoreIQ Admin Dashboard

Versi 1.0.0

Web dashboard admin dengan menggunakan model Machine Learning (Regresi dan Klasifikasi) untuk membantu para admin store dalam memprediksi data penjualan secara lebih akurat dan lebih cerdas secara otomatis. Sistem ini terintegrasi dengan Global Superstore dataset untuk memberikan analitik mendalam.
